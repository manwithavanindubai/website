# Van with Man Dubai - Images

This directory contains the images for the Van with Man Dubai website.

## Required Images

Please download the following images from vanwithmandubai.com and place them in this directory:

1. **slide1.png** - Hero section image
   - Source: https://vanwithmandubai.com/images/slide1.png
   - Used: Hero section background

2. **pickup-truck-rental-dubai.jpeg** - 1.5 Ton Pickup truck
   - Source: https://vanwithmandubai.com/images/pickup-truck-rental-dubai.jpeg
   - Used: Services section - 1.5 Ton Pickup card

3. **hiace-delivery-van-dubai.jpg** - Delivery van
   - Source: https://vanwithmandubai.com/images/hiace-delivery-van-dubai.jpg
   - Used: Services section - Delivery Van card

4. **1-ton-pickup-truck-man-van-dubai.jpg** - 1 Ton pickup
   - Source: https://vanwithmandubai.com/images/1-ton-pickup-truck-man-van-dubai.jpg
   - Used: Services section - 1 Ton Pickup card

## Download Instructions

You can download these images using:

### Option 1: Using curl (if available)
```bash
curl -o slide1.png "https://vanwithmandubai.com/images/slide1.png"
curl -o pickup-truck-rental-dubai.jpeg "https://vanwithmandubai.com/images/pickup-truck-rental-dubai.jpeg"
curl -o hiace-delivery-van-dubai.jpg "https://vanwithmandubai.com/images/hiace-delivery-van-dubai.jpg"
curl -o 1-ton-pickup-truck-man-van-dubai.jpg "https://vanwithmandubai.com/images/1-ton-pickup-truck-man-van-dubai.jpg"
```

### Option 2: Using PowerShell
```powershell
Invoke-WebRequest -Uri "https://vanwithmandubai.com/images/slide1.png" -OutFile "slide1.png"
Invoke-WebRequest -Uri "https://vanwithmandubai.com/images/pickup-truck-rental-dubai.jpeg" -OutFile "pickup-truck-rental-dubai.jpeg"
Invoke-WebRequest -Uri "https://vanwithmandubai.com/images/hiace-delivery-van-dubai.jpg" -OutFile "hiace-delivery-van-dubai.jpg"
Invoke-WebRequest -Uri "https://vanwithmandubai.com/images/1-ton-pickup-truck-man-van-dubai.jpg" -OutFile "1-ton-pickup-truck-man-van-dubai.jpg"
```

### Option 3: Manual Download
Right-click each URL and save the image to this directory.
